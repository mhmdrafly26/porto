Proyek

  1. SQLProbe – SQL Injection Testing Tool

    Tools untuk menguji indikasi kerentanan SQL Injection pada parameter aplikasi web dalam lingkungan pengujian yang diizinkan.

    Python, Requests, Flask, SQLite

    Live demo GitHub

  2. HashForge – Password Hashing Tool

    HashForge adalah tools Cyber Security berbasis web yang digunakan untuk mengenkripsi password menggunakan algoritma hashing yang aman. Tools ini memungkinkan pengguna menghasilkan password hash menggunakan algoritma Argon2id, bcrypt, dan SHA-256, serta melakukan verifikasi password dengan hash yang telah dibuat. Aplikasi ini dirancang untuk membantu developer memahami implementasi hashing dan meningkatkan keamanan penyimpanan password.

    Python 3, Flask, HTML5, CSS3, JavaScript, Argon2 / bcrypt

    Live demo GitHub

  3. PassX – Password Security Analyzer

    PassX adalah tools keamanan untuk menganalisis kekuatan password berdasarkan panjang karakter, kombinasi huruf, angka, simbol, serta tingkat kompleksitas. Tools ini juga memberikan estimasi ketahanan password terhadap brute-force attack dan rekomendasi untuk meningkatkan keamanan password.

    Python 3, Flask, HTML, CSS, JavaScript, zxcvbn (Password Strength Estimation), Bootstrap 5

    Live demo GitHub
